把你的照片
放进这个小宇宙。

主页的 “Try a portrait” 可以试一下照片效果。它只在当前页面预览，不会把照片上传到网上。

正式更换头像

  1. 准备一张 JPG 照片，建议裁成 4:5 竖图，例如 800 × 1000 像素，大小控制在 2 MB 以内。
  2. 把照片命名为 portrait.jpg。如果原图是 PNG 或 HEIC，请先用照片编辑器导出为 JPEG，不要只修改扩展名。
  3. 打开你的 GitHub 网站仓库，进入 assets 文件夹。
  4. 点击 Add file → Upload files，上传 portrait.jpg 并提交更改。
  5. 等待 GitHub Pages 更新后刷新网站。所有访客就能看到你的照片了。

本地操作也一样：将照片放入网站目录下的 assets/portrait.jpg，再提交到 GitHub。

没有照片时，会显示插画占位图。照片以居中裁切显示；想调整取景，可以修改 style.css 中 .portrait-frame img 的 object-position。

隐私小提醒

上传到公开仓库的照片是公开的。发布前可以用照片编辑器导出副本，去掉拍摄地点等 EXIF 信息。
